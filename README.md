# 📊 PhonePe Data Visualization Dashboard

An interactive **Power BI Dashboard** built using **PhonePe transaction data** to analyze digital payment trends and transform raw data into meaningful business insights.

## 🚀 Key Features

* 📈 Interactive KPIs
* 💰 Transaction Analysis
* 🗺️ State-wise Insights
* 📍 District & Pincode Analysis
* 📅 Quarterly & Yearly Trends
* 🎛️ Dynamic Filters & Slicers

## 🛠️ Tech Stack

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
